# КОНТУР — архитектурная студия

Сайт архитектурной студии: пять страниц, адаптивная вёрстка, интерактивное портфолио и форма заявки. Сделан **на чистых HTML, CSS, JavaScript** — без React, сборщиков, платных сервисов и бэкенда.

## Как запустить

1. Распакуйте ZIP полностью (не открывайте HTML прямо внутри архива).
2. Дважды щёлкните по файлу **`index.html`**.
3. Используйте меню для перехода на остальные страницы.

Альтернатива для разработки — VS Code с расширением **Live Server** либо любой локальный HTTP-сервер, например: `python -m http.server 8000` из папки проекта. Открывайте `http://localhost:8000`.

**Внимание к изображениям:** фотографии загружаются по HTTPS с Unsplash и не лежат внутри ZIP. Чтобы видеть реальные фотографии, нужны интернет и доступ к `images.unsplash.com`. Если сеть недоступна, сайт остаётся работоспособным, вместо фотографий отображаются спокойные фоновые заглушки. Шрифты также подгружаются из Google Fonts с системными запасными вариантами.

## Страницы

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная, 3-слайдовый первый экран, направления, подборка проектов, философия, процесс |

## Что работает

- Меню компьютера и полноэкранное мобильное меню. Закрытие по Esc и клику по пункту.
- Фиксированная шапка со сменой оформления при прокрутке.
- Слайдер из трёх фотографий с автопереключением, кнопками и индикаторами; пауза при наведении, фокусе и скрытой вкладке; уважение настройки `prefers-reduced-motion`.
- Появление контента при прокрутке через `IntersectionObserver`.
- Фильтрация портфолио без перезагрузки страницы и счётчик объектов.
- Страница каждого проекта по query-параметру `slug`.
- Полноэкранная галерея с клавишами ← / → / Escape.
- Нативная HTML-валидация полей заявки, дополнительная проверка имени и телефона, подготовка и копирование текста обращения.
- Раскрывающиеся FAQ.
- Адаптивность в мобильных, планшетных и десктопных разрешениях.

## Важно про форму заявки

На сайте **нет сервера или адреса получателя**, поэтому заявка **не отправляется** — ни по почте, ни в базу данных. Форма проверяет ввод и формирует текст, который можно скопировать. Пользователю показывается честное сообщение о результате.

Для реальной отправки есть выделенная настройка `ENDPOINT` в `assets/js/main.js` внутри `initContactForms()`. Нужно добавить собственный безопасный серверный обработчик HTTP POST, защиту от спама, политику обработки персональных данных и реальные реквизиты организации. Не используйте публичные ключи отправки в клиентском коде.


Редактирование проектов: `assets/js/data.js`, массив `projects`. Изменить текст: соответствующая HTML-страница. Цвета, отступы, анимации: CSS-переменные и компоненты в `assets/css/styles.css`.

## Что потребуется для будущей коммерческой версии

- Реальный бренд / домен, юридическая проверка имени, контакты и реквизиты.
- Собственные проекты студии, тексты, изображения с подтверждёнными правами.
- Реальная обработка заявок и защита персональных данных.
- Метатеги для социальных сетей, мониторинг, оптимизация медиаконтента, аналитика и публикация.

### Можно ли потом добавить React, TypeScript и SQL?

Да. Контент уже отделён от страниц в `data.js`, а логика событий — в `main.js`. В дальнейшем можно преобразовать эти данные в типизированные модели TypeScript, выделить компоненты React и заменить локальный массив API, которое будет использовать PostgreSQL или другую SQL-базу. SQL подключается **через сервер**, не напрямую из браузера.
