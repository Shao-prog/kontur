# Фотографии и лицензирование

Фотографии сайта используются для иллюстрации направления архитектуры и дизайна интерьеров. Источник — Unsplash (images.unsplash.com). Это реальные фотографии, не сгенерированные ИИ.

Лицензия: https://unsplash.com/license — допускает использование фотографий на коммерческих и некоммерческих сайтах без обязательной атрибуции. Ограничения остаются, в частности для узнаваемых людей, брендов и отдельных охраняемых объектов. Для настоящего архитектурного бизнеса предпочтительны собственные фотографии с согласованными правами.

В этом проекте фотографии не включены в ZIP. Они подгружаются с CDN при открытии сайта. Для автономного проекта потребуется локально скачать снимки на основании условий лицензии и заменить пути в HTML и `assets/js/data.js`.
